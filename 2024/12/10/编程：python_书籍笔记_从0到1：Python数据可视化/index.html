二、基础图表

2.1 Matplotlib简介

  • 基于Numpy实现的一个库

  • 基础图表：

    -- 折线图：plot()

    -- 柱形图：bar()

    -- 条形图：barh()

    -- 直方图：hist()

    -- 饼状图：pie()

    -- 散点图：scatter()

    -- 箱线图：boxplot()

2.2 基础绘图（折线图）

  • （1）基础语法

    -- plt.plot(x, y)

  • （2）样式定义
    -- ① 线条样式参数(color; linestyle; linewidth)
    -- ② 节点样式参数(marker; markersize或ms; markerfacecolor或mfc; markeredgecolor或mec)

  • （3）实际案例

2.3 通用设置

  • ==与通用设置相关的大多数函数是直接通过pyplot子库来调用的，可以用于大多数图表==

  • 常用的通用设置：

    -- 画布样式：figure()

    -- 定义标题：title()、xlabel()、ylabel()

    -- 定义图例：legend()

    -- 刻度标签：xticks()、yticks()

    -- 刻度范围：xlim()、ylim()

    -- 网格线 ：grid()

    -- 参考线 ：axhline()、axvline()

    -- 参考区域：axhspan()、axvspan()

    -- 注释内容（有指向）：annotate()

    -- 注释内容（无指向）：text()

  • （1）画布样式

    -- plt.figure(figsize, facecolor, edgecolor)

    -- ==由于画布样式针对的是全局，所以figure()函数必须在绘图函数之前调用，不然就会出现问题==

  • （2）定义标题

    -- 主标题：plt.title(label, loc);

    -- x轴标题：plt.xlabel(label, loc);

    -- y轴标题：plt.ylabel(label, loc)

    -- ==标题本质上是文本，既然是文本，我们就可以使用fontsize、color等参数定义样式==

    -- ==在实际工作中，建议在绘图代码的开始处统一加上下面这两句代码:==

  • （3）定义图例

    -- plt.legend(loc)

    -- ==legend()需要结合绘图函数的label参数一起使用，所以必须在绘图函数的后面调用，不然无法生效==

  • （4）刻度标签

    -- x轴刻度标签：plt.xticks(ticks, labels)

    -- y轴刻度标签：plt.yticks(ticks, labels)

  • （5）刻度范围

    -- x轴刻度范围：plt.xlim(left, right)

    -- y轴刻度范围：plt.ylim(left, right)

    -- ==范围包括left也包括right==

  • （6）网格线

    -- plt.grid(axis, linestyle, color)

  • （7）参考线

    -- 水平方向：plt.axhline(y, color, linestyle, linewidth)

    -- 竖直方向：plt.axvline(x, color, linestyle, linewidth)

  • （8）参考区域

    -- 水平方向：plt.axhspan(ymin, ymax, facecolor, alpha)

    -- 竖直方向：plt.axvspan(xmin, xmax, facecolor, alpha)

  • （9）注释文本（有指向）

    -- plt.annotate(text, xy, xytext, arrowprops)

  • （10）注释文本（无指向）

    -- plt.text(x, y, text)

    -- ==text()一次只能为一个节点添加注释文本。如果想要添加多个注释文本，只需要多次调用即可==

2.4 通用样式

  • 有一些样式参数可以被大多数（注意是大多数，并不是所有）绘图函数使用，又叫作“通用样式参数”

  • 详细如下：

    -- color（颜色）

    -- fontsize（字体）

    -- ha（水平对齐，horizontal align的简写）

    -- va（竖直对齐，vertical align的简写）

    -- label（图例）

    -- alpha（透明度，0~1.0）

2.5 散点图

  • 作用：

    -- 判断变量之间是否存在关联趋势，并判断这个关联趋势是线性的还是非线性的

    -- 判断是否有离群点（也叫异常点），也就是偏移量比较大的点

  • （1）基本语法

    -- plt.scatter(x, y)

  • （2）样式定义（marker; color; s; alpha）

  • （3）实际案例

    -- ==多次调用scatter()能绘制多组散点。为了区分不同的组，可以通过设置marker来改变散点的外观==

  • （4）气泡图

    -- 参数s表示点的大小，它的值可以是整数，也可以是列表。

    -- 取值为整数时，所有点的大小是一样的；取值为列表时，会根据列表的值来定义每一个点的大小

    -- color和s一样，它的值除了可以是整数之外，还可以是列表。值为列表时，元素采用不同的颜色

  • ==柱形图也叫作“柱状图”，它的主要作用是展示数据的大小==

  • （1）基本语法

    -- plt.bar(x, y, hatch)

  • （2）实际案例

  • （3）高级绘图（堆叠柱形图；并列柱形图）

  • （4）条形图（plt.barh(x, y, hatch)）

2.7 直方图

  • ==直方图又叫作“质量分布图”，它的主要作用是展示数据的分布情况==

  • ==直方图用于统计每一个分组中数据的个数==

  • 与柱形图的区别：

    -- 柱形图用于展示==数据的大小==，而直方图用于展示==数据的个数（频率）==

    -- 柱形图用于展示==离散型数据的分布==，而直方图用于展示==连续型数据的分布==

    -- 柱形图的柱条之间==有固定的间隙==，而直方图的柱条之间是==没有任何间隙的==

  • （1）基本语法

    -- plt.hist(x, bins)

  • （2）样式定义

    -- histtype、rwidth、facecolor、edgecolor、alpha

  • （3）实际案例

2.8 饼状图

  • 饼状图也叫作“饼图”。==饼状图有些特殊，是没有坐标的，因为它的作用是展示各个部分占总和的比例==

  • 虽然饼状图的展示效果不错，==但它仅适用于少量数据的呈现==

  • （1）基本语法

    -- plt.pie(x)

  • （2）样式定义

    -- labels、colors、autopct、explode、shadow

  • （3）圆环图

    -- ==配合使用pie()函数的radius和wedgeprops这2个参数来实现圆环图==

2.9 箱线图（也叫作“箱形图”）

  • 使用6个统计量来描述数据，即==最大值、上四分位数、中位数、下四分位数、最小值、异常值==

  • 异常值是绘制箱线图时自动识别出的，而不是我们手动设置的

  • （1）基本语法

    -- plt.boxplot(x)

  • （2）样式定义

    -- notch、vert、showmeans、showfliers、flierprops、boxprops、labels

  • （3）实际案例

    -- ==箱线图只是一种辅助工具，并不能保证一定能判断出异常值==
