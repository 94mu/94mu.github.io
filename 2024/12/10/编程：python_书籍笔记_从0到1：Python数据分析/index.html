一、数据分析概述

二、Numpy基础

2.1 Numpy是什么
  • 数据分析“三剑客”指的是NumPy、Pandas、Matplotlib
  • 机器学习算法中用到的大量数组及矩阵运算，也需要借助NumPy来实现。可以这样说，==NumPy是数据科学领域中最基础的一个库==
  • NumPy主要用于操作多维数组，==学习NumPy，其实就是学习数组的各种操作==
2.2 创建数组

  • 在Python中，可以使用NumPy来创建一个数组。数组和列表很相似，但是它们之间有本质上的区别：

    -- 列表的元素可以是不同数据类型，而数组的元素必须是同一数据类型

    -- 列表不可以进行四则运算，而数组可以进行四则运算

  • （1）基本方法

    -- ① array(列表或元组)：将列表或元组转换为数组；==数组元素之间是用空格隔开的，而不是用逗号隔开的==

    -- ② arange(start, end, step)：创建在“指定范围的==一维数组==，不能创建多维数组；==取值范围[start, end)==；==当只有一个参数时，表示只有结束值，开始值是0；==步长可以任意数，range()步长必须整数

    -- ③ linspace(start, end, num, endpoint=True或False)：取值范围为[start, end]；可以使用endpoint=False，使得它的取值范围为[start, end)

    -- ④ zeros((a, b, …, n), dtype=int或float)：创建一个元素值全为0的a×b×…×n数组；元素类型默认为float类型，可以使用dtype=int改为int类型。

    -- ⑤ ones((a, b, …, n), dtype=int或float)：创建一个元素值全为1的a×b×…×n数组；元素类型默认为float类型，可以使用dtype=int改为int类型。

  • （2）随机数组（random模块）

    -- ① random.randint(start, end, size=元组或整数)：随机整数，范围为[start, end)

    -- ② random.rand(m, n)：随机浮点数，范围为[0, 1)

    -- ③ random.randn(m, n)：随机浮点数，符合正态分布

  • （3）数组和列表的区别（==在内存中的存储方式不同，列表相对数组更耗费资源==）

2.3 数组属性

  • 在NumPy中，一个数组就是一个ndarray对象。==ndarray，是n dimension array （N维数组）的缩写==

  • 数组的属性非常多，常用的属性如下：

    -- ndim：维度的个数，即多少维，n dimension的缩写

    -- shape：数组的形状，比如m行n列

    -- size：元素的个数

    -- dtype：元素的类型，data type的缩写

  • 在NumPy中，对于一个数组来说，所有元素的类型都是相同的，==所以数组的类型其实指的就是它元素的类型。==

2.4 元素操作
  • ==一般来说，NumPy提供的方法不会修改原数组==
  • （1）访问元素（==在NumPy中，使用下标来访问数组中的元素，这一点和列表是一样的==）
  • （2）修改元素（==在NumPy中，也是使用下标来修改某一个元素的值。对于二维数组来说，还可以修改一整行或一整列的值==）
  • （3）添加元素（np.append(arr, value, axis=n)；使用append()在数组的末尾添加一个新元素；==append()并不会修改原数组，而是会返回一个新数组==）
  • （4）删除元素（np.delete(arr, m, axis=n)；==delete()不仅可以删除某一个元素，还可以删除某一行或某一列。==）
  • （5）切片（NumPy支持使用“…”（3个点号）来表示剩余的轴）
2.5 数组操作
  • ① 修改形状；② 修改维度；③ 翻转数组；④ 数组去重；⑤ 合并数组；⑥ 分割数组
  • （1）修改形状（arr.reshape(m, n)；==重塑前后两个数组的元素个数必须相同==）
  • （2）修改维度（np.array(arr, ndmin=n)；==ndmin参数只能将低维度数组转换为高维度数组，而不能将高维度数组转换为低维度数组==）
  • （3）翻转数组（np.transpose(arr)；==翻转数组指的是将“m×n的数组”转换成“n×m的数组”==）
  • （4）数组去重（np.unique(arr)；==将数组中重复的数字去除，然后将剩余的数字组成一个新的一维数组==；==不管是多少维的数组，unique()返回的都是一个一维数组==）
  • （5）合并数组（==① ==np.concatenate((arr1, arr2), axis=n)；==②== np.hstack()；==③== np.vstack()；==④== np.stack((arr1, arr2), axis=n)）
  • （6）分割数组（==①== np.split(arr, section=整数或数组, axis=n)；==②== np.vsplit()；==③== np.hsplit()）
2.6 各种运算

  • （1）基本运算（加、减、乘、除、求余、求幂）

    -- 运算符（+、-、、/、%、**）

    -- 函数（add(a, b)、subtract(a, b)、multiply(a, b)、divide(a, b)、mod(a, b)、power(a, b)）

    -- ==在实际开发中，更推荐使用运算符的方式来进行计算==

  • （2）比较运算（大于、小于、大于等于、小于等于、等于、不等于）

    -- ==两个数组的形状必须相同，或者符合广播机制==

  • （3）标量运算（==可以简单理解为将一个数组和一个数进行加、减、乘、除等操作；==不管是多少维的数组，==标量运算都是对数组中每一个元素进行相同的操作==）

  • （4）数学函数（square()；abs()；sqrt()；around()；ceil()、floor()；reciprocal()；sin()、cos()、tan()）

  • （5）统计函数（sum()；max()；min()；median()；mean()；var()；std()；average()；percentile()）

2.7 遍历数组（在NumPy中，遍历数组和遍历列表一样，也是使用for循环来实现的）
  • 对于一维数组，直接使用for循环就可以把每一个元素遍历出来
  • 对于二维数组或更多维数组来说，使用for循环遍历时，默认情况下是针对第一个轴（axis=0）来进行的。==如果要遍历数组的所有元素，则需要使用数组的flat属性==
2.8 大小排序

  • 在NumPy中，可以使用sort()来对数组进行排序。由于数组对象和NumPy都有sort()，所以需要分成以下两种情况来考虑：

    -- 如果是在“数组对象”上调用sort()，则会对数组本身进行排序

    -- 如果是在“NumPy”上调用sort()，则会返回该数组对象的排序副本

  • 默认情况下，sort()实现的是升序排列，也就是从小到大排序。如果想要实现数组的降序排列，可以使用一种变通的方式（result = arr[::-1]）

三、Numpy进阶

3.1 浅拷贝和深拷贝

  • （1）浅拷贝

    -- 指的是对一个数组对象拷贝之后，虽然前后两个数组对象是不同的对象，但是它们的数据是共享的（==藕断丝连==）

    -- 语法：arr.view()

  • （2）深拷贝

    -- 指的是对一个数组进行拷贝之后，前后两个数组对象是不同的对象，数据也不是共享的（==老死不相往来==）

    -- 语法：arr.copy()

  • 在实际开发中，==较少使用浅拷贝，更多是使用深拷贝这种方式==

3.2 axis的值
  • 设置axis这个参数是因为在NumPy中，操作多维数组时需要指定对哪一维操作，==而axis就是用来指定需要操作哪一维==
  • ==axis为大于或等于0的整数==，axis=0表示对第1维进行操作，axis=1表示对第2维进行操作，==以此类推==
  • ==在实际开发中，数组大多数是二维数组，所以只需要记住==：当axis=0时，表示沿着“纵轴”操作；当axis=1时，表示沿着“横轴”操作。
  • 详见书
3.3 广播机制
  • ==“形状不同”的数组也能进行运算==，但是需要满足一定的条件才行
  • （详见书）
3.4 读写文件
  • 对于NumPy的文件读写，==一般使用CSV这种文件格式==
  • CSV是一种非常重要的文件格式，它可以和Excel文件进行互相转换
  • （1）读取文件（np.loadtxt(path, delimiter=”分隔符”)）
  • （2）写入文件（np.savetxt(path, arr, delimiter=”分隔符”)）
3.5 矩阵简介
  • 在NumPy中，矩阵和数组是两种不同的数据类型。==虽然它们很相似，但是有着本质上的区别。数组是一个ndarray对象，矩阵是一个matrix对象。==
  • 矩阵都是二维的，可以把它看成一种特殊的二维数组。NumPy官方建议，==如果在某种情况下矩阵和数组都适用，那就选择数组==
  • 在NumPy中，不管是哪一种矩阵，都是使用matlib模块的方法来创建的
  • 默认情况下，矩阵元素类型是浮点型，可以使用dtype=int将其类型定义成整型。
  • （1）全0矩阵（np.matlib.zeros((m, n))）
  • （2）全1矩阵（np.matlib.ones((m, n))）
  • （3）单位矩阵（np.matlib.identity(m)）
  • （4）随机矩阵（np.matlib.rand(m, n)）

第二部分 Pandas篇

四、 Pandas简介

4.1 Pandas是什么
  • Pandas是基于NumPy实现的一个非常重要的数据分析库。==在实际的工作中，我们更多是使用Pandas来进行数据分析，而不是使用NumPy==
  • 实际上，==Excel是使用“软件”的方式来操作一张数据表，而Pandas是使用“编程”的方式来操作一张数据表==
  • 用一句话来概括它：==Pandas就是用于操作一张二维数据表的工具==
4.2 Series

  • Pandas提供了两种数据结构：==Series（系列）和DataFrame（数据帧）==

  • ==Series可以看成一种特殊的一维数组==，==而DataFrame可以看成一种特殊的二维数组==

  • （1）创建Series

    -- 语法：pd.Series(data, index=列表)

    -- ① data是一个列表（详见书）

    -- ② data是一个字典（详见书）

  • （2）Series的属性

    -- ① index：行号（索引）

    -- ② values: 数据（值）

  • （3）获取某行的值

    -- 语法：se.loc[行名]

  • （4）深入了解

    -- Series和字典非常相似。Series的index对应字典中的key，Series的data对应字典中的value。因此，Series也可以由现有的字典直接转换而成。

    -- Series和字典还是有着本质上的区别：① 字典是无序的，而Series是有序的；② 字典的key是不可变的，而Series的index是可变的；③ Series提供了大量的统计方法，但是字典没有

  • 在实际开发中，==更多的是使用DataFrame，而不是使用Series。==主要是因为Series是一维的，而实际开发中的数据更多是二维的

4.3 DataFrame

  • DataFrame是Pandas中==最重要的一种数据结构==。对于DataFrame，可以把它看成一种特殊的二维数组。

  • （1）创建DataFrame

    -- 语法：pd.DataFrame(data, index=列表, columns=列表)

    -- ① data是一个列表（==列表只能是这两种形式：每一个元素都是一个列表；每一个元素都是一个字典==）

    -- ② data是一个字典（当data是一个字典时，==字典的key会作为DataFrame的列名，字典的value会作为DataFrame的数据==；需要注意的是，字典的每一个value都要求是一个列表或者一个值）

  • （2）DataFrame的属性

    -- ① dtypes：DataFrame的类型（==系统会把DataFrame每一列的类型分别列举出来==）

    -- ② values：DataFrame的数据（值）（==DataFrame的值会以数组的形式返回==）

    -- ③ index：行名（索引）

    -- ④ columns：列名

    -- ⑤ shape：形状，也就是行数和列数。shape[0]表示获取行数，shape[1]表示获取列数

    -- ⑥ size：元素的个数

  • （3）深入了解

    -- ① 文件格式（==当data是一个列表时==，如果想将DataFrame保存到文件中，==一般是保存到CSV文件中==；==当data是一个字典时==，如果想将DataFrame保存到文件中，==一般是保存到JSON文件中==）

    -- ② 对齐输出（在print()语句的前一行加上 pd.set_option("display.unicode.east_asian_width", True)）

    -- ③ 不需要指定行名（在实际工作中，创建DataFrame时，一般需要指定列名，但不需要指定行名。如果不显式指定行名，那么它就是从0开始的连续整数。）

  • （4）实际数据

九、时间序列

9.1 时间序列概述

  • （1）在Pandas中，时间序列用一句话来解释就是：以时间作为行名的Series或DataFrame。一般情况下，时间序列是DataFrame的形式，很少是Series形式。

  • （2）转换类型

    -- 时间序列要求行名是时间对象，而不是字符串，所以需要进行类型转换

    -- pd.to_datetime(列)：只有符合特定5种形式的字符串才可以被转换成Pandas支持的时间对象

    -- 其实不管是哪种类型转换，大多是为了能够使用目标类型提供的各种方法

  • （3）获取日期

    -- df.index.属性（year、month、day、weekday、quarter、is_leap_year）

  • （4）索引与切片

    -- df["2022"]：获取2022年的数据；df["2022-01"]：获取2022年1月的数据；df["2022" : "2023"]：获取2022年~2023年间的数据

9.2 重采样：resample()

  • 重采样（resample）是基于时间的一个分组操作

  • df.resample(freq, axis=0或1).统计函数()：(freq：采样频率；D、M、Y、Q、W)

  • （1）降采样：从高频到低频的操作，例如把天数据变成周数据

    -- ==df.resample(“1W”)并不等价于df.resample(“7D”)==

  • （2）升采样：从低频到高频的操作，例如把周数据变成天数据，数据怎么扩展为7个数据呢？因此会导致有一部分数据是缺失的。对于升采样导致的缺失值，一般使用填充的方式来处理。

    -- ① 向前填充：ffill()：是指使用前一个数据来进行填充

    -- ② 向后填充：bfill()：是指使用后一个数据来进行填充

9.3 移动计算：rolling()
  • 在实际工作中，我们可能会遇到这样一种需求：每天都计算一次3天内的销量总和。例如，第3天要计算一次“1～3天”的销量总和，第4天要计算一次“2～4天”的销量总和，以此类推。
  • df.rolling(n)
  • 实际工作中，移动计算可以用于普通的DataFrame，不过更多是用于时间序列。
9.4 分组器：Grouper()
  • 在Pandas中，可以使用Grouper()来指定分组的依据。在实际工作中，Grouper()一般和groupby()搭配使用。
  • pd.Grouper(key, freq)：key是一个可选参数，表示根据某个列名进行分组。freq也是一个可选参数，表示根据时间频率进行分组。
